# Use a reverse proxy to protect your OM server

If you followed our tutorials ([01_Install_required_module](./01.Install_required_modules.md) 
and [02_Install_openmeta](03.Install_openmeta_with_details.md)) to deploy OM, you can notice the OM server is
exposed directly to the public.

To secure it, we want to use a Revere proxy to handle all incoming requests.

In this tutorial, we will show how to 


## Install nginx

```shell
sudo apt install nginx
```

## Configure virtual host

You need to go add a new host file into nginx

```shell
cd /etc/nginx/sites-available

sudo vim openmetadata
```

Add the below content to the file

```shell
# set a backend upstream
upstream openmeta {
    server 127.0.0.1:8585 fail_timeout=0;
}

upstream airflow {
    server 127.0.0.1:8080 fail_timeout=0;
 }

# a server listen to port 80, which will redirect request to port 443
server {
    listen 80;
    server_name om-dev.casd.local;

    # all request will be redirected to the backend_chart upstream
    location / {
        include proxy_params;
        proxy_pass http://openmeta;
    }

    }

# a server listen to port 80, which will redirect request to port 443
server {
    listen 80;
    server_name om-dev-airflow.casd.local;

    # redirect http request to https
    return 301 https://$host$request_uri;

    }


# a server listen to port 443, which will ensure https resolution
server {
    listen 443 ssl;
    server_name om-dev.casd.local;
    ssl_certificate /etc/ssl/certs/wildcard-casd.pem;
    ssl_certificate_key /etc/ssl/private/wildcard-casd.key;

    # all request will be redirected to the backend_chart upstream
    location / {
        include proxy_params;
        proxy_pass http://openmeta;
    }
}

server {
    listen 443 ssl;
    server_name om-dev-airflow.casd.local;
    ssl_certificate /etc/ssl/certs/wildcard-casd.pem;
    ssl_certificate_key /etc/ssl/private/wildcard-casd.key;

    # all request will be redirected to the backend_chart upstream
    location / {
        include proxy_params;
        proxy_pass http://airflow;
    }
}
```

Now we need to enable the host

```shell
cd /etc/nginx/sites-enabled

# create a symbolic link 
ln -s /etc/nginx/sites-available/openmetadata openmetadata

# restart the nginx server
sudo systemctl restart nginx
```
