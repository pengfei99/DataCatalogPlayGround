# Post installation config

## Remove default admin account

The default OM config will initiate a default admin account in your OM database. Once you have created an admin account,
you need to remove the default account, or at least modify the default password.

The default credential of the admin account depends on your authorizer config. If you used the original config. The
login and password will be. 
```powershell
login: admin@open-meta.org
pwd: admin
```

If you changed the config, for example as the below one.

```yaml
config:
    authorizer:
      adminPrincipals: [admin]
      principalDomain: "casd.eu"
```

As you change the `principal domain`, the login and password will be. 
```powershell
login: admin@casd.eu
pwd: admin
```

You need to log in to the admin account and change the password via the OM web interface. 

`Settings->Team & User Management->Admins`, you should see a list of admin users. Click on admin, and change the 
password.

If you log in as admin users, you can grant other users the `admin` role.

> After you create other admin user accounts, you can delete the default one.
